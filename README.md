# SmartNet Manager 🌐

Projeto desenvolvido em C# como atividade avaliativa da plataforma de ensino Ada Tech, integrante da formação continuada **CAIXAVERSO | Dev Back-end C# - I**.

O objetivo deste projeto é aplicar conceitos fundamentais de desenvolvimento back-end utilizando estruturas de dados, programação orientada a objetos e recursos da linguagem C# em uma aplicação de console.

O sistema simula operações básicas de gerenciamento de dispositivos em uma rede corporativa, permitindo o cadastro, autenticação, monitoramento e controle de dispositivos conectados.

## Tecnologias Utilizadas

- C#
- .NET
- Visual Studio Code
- Git e GitHub

## Como Executar

Clone o repositório:

```bash
git clone <url-do-repositorio>
```

Acesse a pasta do projeto:

```bash
cd SmartNetManager
```

Execute a aplicação:

```bash
dotnet run
```
